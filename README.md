## 소개

관광객이 부산 명소 8곳에서 체크인하면 장소별 스탬프 토큰이 Solana devnet에 발행됩니다.
스탬프 4개를 모으면 지역 상점 쿠폰 토큰이 발급되고, 쿠폰 사용 시 토큰이 소각(burn)되어 이중 사용이 차단됩니다.
권역별 스탬프 발행량은 민트 공급량에서 직접 읽어 도시 대시보드에서 공개합니다.

| 구분 | 명소 |
|------|------|
| 동부산 | 해운대해수욕장 · 광안리해수욕장 · 해동용궁사 |
| 서부산 | 감천문화마을 · 송도해수욕장 |
| 원도심 | 자갈치시장 · 태종대 · 용두산공원·부산타워 |

## 작동 방식

1. 체크인 → 명소별 SPL 토큰 민트에서 방문자 지갑으로 스탬프 1개 발행
2. 스탬프 4개 도달 → 쿠폰 청구(쿠폰 민트에서 토큰 1개 발행, 중복 청구 방지)
3. 쿠폰 사용 → 토큰 소각으로 교환 완료 처리
4. 대시보드 → 전 명소의 민트 공급량을 읽어 권역별 발행량 집계

핵심 모듈: `lib/wavepass.ts`(발행·청구·소각), `lib/send.ts`(서명 상태 폴링 기반 전송 — 기본 sendAndConfirm이 느린 네트워크에서 실제 착지한 트랜잭션을 만료로 오판하는 문제를 회피), `lib/spots.ts`(명소 데이터), `lib/server.ts`(서버 상태).

## 실행

```bash
npm install
npm run dev        # http://localhost:3100
npm run build      # 프로덕션 빌드
npm start          # 프로덕션 실행 (포트 3100)
npm run smoke      # devnet 스모크 테스트 (스탬프 발행 → 쿠폰 발행 → 소각)
npm run typecheck
```

- 네트워크: Solana **devnet** 전용 데모입니다. 실자산과 무관합니다.
- 운영자·방문자 데모 지갑과 상태 파일은 `.local/`(git 제외)에만 보관되며 저장소에 포함되지 않습니다. 서버를 처음 실행하면 데모 지갑이 자동 생성되고, 온체인 기능을 쓰려면 운영자 지갑에 devnet SOL이 필요합니다(https://faucet.solana.com — 공개 RPC의 `requestAirdrop`은 현재 닫혀 있어 웹 파우셋을 사용하세요).

## 검증

- devnet 스모크 테스트 전체 통과 (스탬프 발행·보유 확인·쿠폰 발행·쿠폰 소각 교환)
- 웹앱 전 구간 실측 완료 (체크인 → 스탬프 4개 → 쿠폰 청구 → 잔액 확인)
